# Getting Started

Follow these pages in order for a first working Pyrofork application:

1. [Install Pyrofork](installation.md).
2. [Create a project and obtain Telegram API credentials](setup.md).
3. [Authorize a user account or bot](authorization.md).
4. [Send a request with a Client method](calling-methods.md).
5. [Listen for Telegram updates](updates.md).
6. [Handle API and RPC errors](error-handling.md).

Then browse [examples](../examples/README.md), or choose a topic from the [guides](../guides/README.md).
