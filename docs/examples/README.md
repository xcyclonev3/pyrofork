# Examples

These examples are small starting points for common user clients and bots. Add your own API ID and hash, bot token where
needed, and chat identifiers before running them. The first authorization creates a session file; keep it private.

## First clients

- [Hello world](hello_world.md) — connect a user client and send a message.
- [Echo bot](echo_bot.md) — reply to messages received by a bot.
- [Welcome bot](welcome_bot.md) — greet new group members.

## Messages and keyboards

- [Bot keyboards](bot_keyboards.md) — reply keyboards and inline keyboards.
- [Callback queries](callback_queries.md) — handle presses on inline keyboard buttons.
- [Inline queries](inline_queries.md) — answer inline queries sent to a bot.
- [Use inline bots](use_inline_bots.md) — query and send results from another inline bot.

## Read chats and updates

- [Get dialogs](get_dialogs.md) — iterate over the current account's dialogs.
- [Get chat history](get_chat_history.md) — retrieve messages from a chat.
- [Get chat members](get_chat_members.md) — iterate over chat members.
- [Raw updates](raw_updates.md) — receive updates that do not have a high-level handler.

Review [authorization](../getting-started/authorization.md) and the
[API reference](../api/README.md) before adapting examples for production.
